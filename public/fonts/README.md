# Custom Brand Fonts Slot

Drop your custom font files here to automatically use them across the website:
- `Quagera.woff2` or `Quagera.woff` (for luxury serif headings)
- `HDColton-Regular.woff2` or `HDColton-Regular.woff` (for clean editorial sans-serif typography)

The project includes pre-configured `@font-face` definitions in `src/app/globals.css` and luxury Google Font fallbacks (`Cormorant Garamond` and `Montserrat`), ensuring that typography is pixel-perfect out of the box and seamlessly switches to Quagera and HDColton as soon as the font files are dropped here!
